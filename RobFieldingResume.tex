Contributed for about six months to the Check Point Ext JS web console. Worked on SensorNet, an experimental Hadoop analysis project applying PageRank to graphs of communicating nodes. Also worked on Project MSSP, a web-based log collector for subscribed customers' Check Point firewalls.

\tech{C and C++ (4 years); Ext JS and PHP (2 years); Java (6 years); Python, Celery, and RabbitMQ (2 years); Linux (10 years); cryptography (8 years)}
